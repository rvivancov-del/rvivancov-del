## 🚚 Proyecto destacado: FlotaControl

**[control_flota](https://github.com/rvivancov-del/control_flota)** es mi trabajo de titulación: un sistema web con arquitectura de microservicios para el control de costos operativos y el mantenimiento de una flota de transporte de carga pesada, con priorización del mantenimiento mediante AHP.

**Qué hace:**
- **Costos:** calcula el costo real de cada camión y de cada kilómetro, la utilidad y el margen. Está validado con un mes de datos reales de la empresa caso, con una diferencia de −0,48 % en el costo total.
- **Mantenimiento:** genera alertas por kilometraje y un ranking AHP con los juicios de expertos del sector (CR = 0,0115).
- **Despacho:** el conductor registra la salida del viaje desde el celular con una credencial QR, sin usuario ni contraseña.
- **Calidad:** 910 pruebas automatizadas (909 aprobadas), 80 % de cobertura e integración continua con GitHub Actions.

**Arquitectura:** tres microservicios FastAPI, un API gateway con Nginx, PostgreSQL con un rol por servicio y un frontend en React con TypeScript, todo con Docker Compose.
